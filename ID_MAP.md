# ID map

Every class ID from inventory/class-ids.md appears here exactly once, with its new ID, a disposition and the reason. The class IDs come from the class rules record: main 58a1477, the base commits a853795 and 1124404, every PR head (#1, #3-#15) and every PR body. New IDs use the prefixes PUR (Purchase), PMT (Payment) and AXS (Access), which never appear in the class record.

Dispositions:

- kept: the same meaning, now under a new ID (its status may become Decided).
- merged: folded with other class IDs into one new ID.
- superseded: replaced by a different rule or term, or a question answered by a decision (D1 to D28). New ID names the replacement.
- rejected: nothing to carry (referenced but never defined, or not a class ID).

The question labels without a prefix (Q01, Q03, Q05, Q06, Q07, Q-ACC-n, Q-MET-n, Q-SLOT-n) are listed too. EX-T05 is not a class ID (the inventory's "Not IDs" table); it has a rejected row so that every label the inventory names is accounted for. The unnumbered booking-price rule, "(no ID)" in the inventory, is the last row, with a longer note in its own section below. The known conflicts K1-K8 (inventory/rules-prs.md section 17) are resolved in the rows; the last table points at them. O-numbers are the other conflicts in section 19 of the same file. O5: every class context outside the three maps to one of them: Shared journey, Identity, Booking, Reporting and Space Management / Inventory to Purchase; Access / Door to Access.

## The unnumbered booking-price rule

- Class source: "Booking price — Purchase rule clarification", class rules main, clarified by the course instructor in class rules PR #14 (25ca71e, merged as 58a1477). It is the only stakeholder-clarified rule in the class record. It has no stable ID (conflict O1) and asks to be consolidated into PRC-R01 (class rules PR #4 at 9478b3e).
- Class meaning: "for a booking not covered by a subscription, Purchase calculates its booking price using the space's hourly rate at booking creation multiplied by the booked duration, rounded to the nearest whole cent; half cents round up." Payments consumes the recorded amount and does not recalculate it. D8 also stores the same price on plan bookings, which the clarification leaves to PAY-R01 ("subscription coverage remains PAY-R01"), so the price is known whatever the coverage.
- New ID: PUR-R17, Stakeholder-clarified (course instructor, class rules PR #14 at 25ca71e, merged as 58a1477).
- Disposition: merged. PRC-R01 and PRC-R02 (class rules PR #4 at 9478b3e) are merged into PUR-R17 (conflict O2: #4's "observed" status was stale against main). D8 applies the rule to whole 30-minute blocks and satang; Payment never re-prices (PMT-R04).
